# THE CLEAN CARE MANAGER V11

V10 기반 정기청소 월 청구서 일괄 생성 기능 추가.

## 사용 방법
1. 고객 관리에서 정기청소 고객의 청소 주기, 월 계약금액, 세금계산서 여부, 계약 시작/종료일, 입금일을 등록합니다.
2. 청구 메뉴의 **정기청소 월 청구서 자동 생성**에서 청구월을 선택합니다.
3. 미리보기에서 금액과 입금예정일을 확인한 후 **정기청구서 생성**을 누릅니다.
4. 같은 고객·청구월·정기청소 유형의 청구서는 다시 생성하지 않습니다.
5. 일회성 청소는 기존 청구 등록에서 **추가청소·기타**로 별도 등록합니다.

## 주요 사항
- 월 계약금액이 0원이거나 계약기간 밖인 고객은 제외됩니다.
- 고객의 입금일은 `매월 10일`, `익월 10일`, `매월 말일`, `익월 말일` 등을 인식합니다. 미입력 시 선택한 기본 예정일을 사용합니다.
- 세금계산서 발행 고객은 월 계약 공급가액에 10%를 더한 청구액을, 미발행 고객은 계약금액 그대로를 사용합니다(내부 관리용).
- 청구서 생성만으로 매출이 추가되지 않습니다. 수입지출에서 실제 입금 거래를 청구서에 연결해야 수금액이 반영됩니다.
- 웹앱이 닫힌 상태에서 자동 실행되지는 않습니다. 청구 메뉴에서 생성 버튼을 누르는 방식입니다.
