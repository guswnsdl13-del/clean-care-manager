THE CLEAN CARE MANAGER V18

V17 기반 업데이트. 기존 로컬 저장 키 tcc-manager-v3 유지.

1. 청구 내역을 완납 / 미수·부분입금 두 그룹으로 분리. 각 그룹 건수 및 합계 표시.
2. 대시보드 정기계약·입금 현황에 정기 입금 / 일회성·추가청소 입금 / 전체 입금 분리.
3. 일회성 직접 입력, 고객관리 주기가 일회성인 고객, 추가청소 청구서에 연결된 거래를 일회성·추가청소로 분류. 각 거래는 한 번만 집계.
4. 월별·연도별 입금일 기준 조회 유지. 청구 자체는 매출에 중복 산입하지 않음.
5. 기존 V17 기능 및 데이터 저장 키 유지.
