# THE CLEAN CARE MANAGER V12

- 고객 관리에 기본 입금예정일 입력을 배치하고 정기 청구서 및 수입지출 고객 자동입력에 연결합니다.
- 매출 거래에서 고객 선택 시 계약금액, 세금계산서 여부, 결제방법, 기본 입금예정일 안내, 같은 청구월 청구서 1건 자동 연결.
- 청구 메뉴는 삭제하지 않고 선택 사용으로 유지해 기존 청구서 및 미수금 데이터를 보호합니다.
- 목표 달성 현황과 정기계약 입금 현황에 각각 2020~2035년 및 1~12월 조회 기능을 추가합니다.
- 월 매출 현황 제목을 대시보드 매출 합계 위에 배치하고 조회 월 입력을 함께 이동합니다.
- 실제 입금일은 수입지출 거래에 직접 입력합니다. 고객의 입금예정일은 실제 입금일로 자동 확정하지 않습니다.
- 기존 localStorage 키 tcc-manager-v3를 유지합니다. 업데이트 전 JSON 백업을 권장합니다.
