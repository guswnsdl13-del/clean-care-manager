# THE CLEAN CARE MANAGER V5

- V3/V4와 동일한 localStorage 키 `tcc-manager-v3` 사용: 기존 입력 자료 유지
- 미발행 매출 신규 입력 및 수정 시 부가세 0원 자동 고정(내부관리용)
- 세금계산서 발행 매출: 공급가액 × 10% (원 단위 반올림), 포함 합계 = 공급가액 + 부가세
- 미발행 이체 매출: 세금계산서 미발행 + 계좌이체 + 입금완료 거래만 합산
- 기존 거래는 임의로 재계산/수정하지 않음. 이전에 잘못 입력한 건은 거래 내역의 수정 버튼으로 수정
- 일정/견적/D-day/고객/거래 수정 기능 유지
- 업로드: index.html, manifest.json, sw.js를 기존 GitHub 저장소 최상위에 업로드 및 Commit
- 필수: 업데이트 전에 V3/V4 JSON 백업 파일 보관

**주의:** 미발행 거래의 부가세 0원 표시는 사용자 요청에 따른 내부 관리 규칙이며 법적 면세나 부가세 신고 제외를 뜻하지 않습니다.
