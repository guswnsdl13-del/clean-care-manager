# THE CLEAN CARE MANAGER V7

## 업데이트
- 2026년 11월 사업 현황처럼 선택 월 타이틀을 크게 강조했습니다.
- 월 목표 매출 10,000,000원(변경 가능), 달성률, 잔여액, 전월 증감률, 경과율, 예상 월말 매출을 추가했습니다.
- 목표액은 기존 데이터의 settings.monthlyGoal로 저장되며 JSON 백업에도 포함됩니다.
- 매출/지출 그래프(월별/연도별), 거래 수정 및 매출·지출 분리, 고객·일정·견적·D-day 기능을 유지했습니다.
- V6의 JavaScript 문자열 문법을 점검하고 수정된 파일을 배포합니다.

## 갤럭시 업데이트
1. 앱에서 전체 JSON 백업을 다운로드합니다.
2. ZIP 압축을 풀고 index.html, manifest.json, sw.js를 기존 GitHub 저장소의 최상위 폴더에 업로드합니다.
3. Commit changes 후 기존 GitHub Pages URL을 새로 엽니다.
4. V7 표기와 고객/매출 내역, 월별·연도별 그래프를 확인합니다.

데이터는 기존 localStorage 키 tcc-manager-v3를 계속 사용합니다. 다른 기기나 브라우저 사이 자동 동기화는 지원하지 않습니다. 월 목표는 부가세 포함 전체 매출 기준이며 미수금도 포함될 수 있습니다.
