# THE CLEAN CARE MANAGER V2

## 추가된 기능
1. 고객 관리: 업체명, 담당자, 연락처, 주소, 청소 주기, 월 계약금액, 메모
2. 월별 통계: 최근 6개월 매출·지출 막대그래프
3. 반복 청소 일정: 매주 / 2주마다 / 매월 일정 일괄 생성(4·8·12회)
4. 견적 관리: 방문일, 제시 견적, 상태, 미계약 사유 및 계약 전환율
5. 현장 사진: 전·후·작업 중 사진 다중 등록, 크기 축소 후 로컬 저장
6. 전체 백업/복원: 사진을 포함한 JSON 백업, 거래 CSV 내보내기

## GitHub Pages 설치
1. ZIP 압축을 풉니다.
2. GitHub에서 새 Public repository를 만듭니다.
3. index.html, manifest.json, sw.js를 저장소 최상위에 업로드합니다.
4. Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. 생성된 HTTPS 주소를 갤럭시 Chrome에서 엽니다.
6. Chrome 메뉴(⋮) → 앱 설치 또는 홈 화면에 추가를 선택합니다.

## 중요
- 데이터는 해당 휴대폰의 브라우저 로컬 저장공간에만 저장됩니다. 자동 동기화/로그인/서버 백업은 없습니다.
- 사진은 최대 긴 변 1100px, JPEG로 축소해 저장하지만 사진을 많이 보관하면 브라우저 저장 한도에 도달할 수 있습니다. 사진이 많은 경우 정기적으로 JSON 백업을 하고 원본 사진은 갤러리에도 별도 보관하세요.
- 이전 V1 데이터는 자동 이전되지 않습니다. V1을 사용 중이라면 V1에서 JSON 백업 후, V2 설치 후 V2의 복원 기능으로 불러오세요. V1 백업에는 V2 신규 고객·사진 항목이 없으므로 해당 항목은 새로 입력해야 합니다.
- 세무 신고용 공식 장부가 아닌 내부 관리용 도구입니다.
